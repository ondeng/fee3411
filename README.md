# FEE3411 — Control Systems A

Course site for FEE3411 Control Systems A, Department of Electrical and
Information Engineering, University of Nairobi. Covers modelling of physical
systems, transfer functions and block diagrams, transient and steady-state
response, stability analysis (Routh-Hurwitz, root locus, Nyquist), and
frequency-response design with Bode and Nichols plots.
