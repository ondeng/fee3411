# Syllabus

**FEE 411 — Control Systems A** (45 hours)

**Prerequisites:** FEE 222, FEE 372

## Purpose of the course

To introduce control engineering concepts and example control systems, and
provide analytical skills for time- and frequency-domain analysis of control
systems.

## Expected learning outcomes

At the end of this course, the learner should be able to:

1. Describe the working principles of a given control system
2. Analyse a control system solution in the time- and frequency-domains
3. Design a control system to control operations of a simple application
4. Analyse the stability of a control system and design a strategy for its
   enhancement

## Course content

**Introduction.** Examples of control systems. Open- and closed-loop
classification. Control system components and devices. Servomechanisms,
stepper motors, hydraulic systems, pneumatic systems, valves, cylinders and
rotary actuators.

**Time-domain linear systems analysis.** Inputs, plant and outputs, block
diagrams, mathematical models. The characteristic equation. Linear
approximation to nonlinear systems. Analysis of linear (causal) systems as
exemplified by first- and second-order systems. Steady-state and transient
responses. Continuous and discrete time-invariant systems. Delay time.

**Transfer functions.** Laplace transform solution to a linear
constant-coefficient differential equation. Transfer functions as developed
from system differential equations. Definitions and properties in the
s-plane. Block diagrams and canonical feedback. Derivation of transfer
functions from the reduction of elementary block diagrams. Construction of
signal flow diagrams. Block diagram reduction using signal flow diagrams.

**s-domain analysis.** Characteristic equation, pole-zero map, system
stability, Routh–Hurwitz stability criterion, root locus. Standard inputs.
Steady-state errors. System design and simulation.

**Frequency-domain linear systems analysis.** Transfer function frequency
response, bandwidth. Nyquist analysis: complex functions of a complex
variable, singularity of a function, closed contour and encirclement,
mapping properties of a complex function in the s-plane, polar plots and
their properties, Nyquist path, Nyquist plot, Nyquist stability criterion,
relative stability, Bode plot, gain margin, phase margin, resonant peak,
resonant frequency, Nichols chart, Nichols plot.

## Mode of delivery

Lectures, tutorials, group-based learning, class exercises, assignments
(face-to-face or ODEL-based). 2-hour lectures and 1-hour tutorial per week.
